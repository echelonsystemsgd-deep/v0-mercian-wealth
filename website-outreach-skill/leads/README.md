# Leads Directory

This folder is intentionally empty in the student package. Do not distribute real or test campaign records with the skill.

Place one intended CSV here before running `prompt.MD`. Required data is an email and should normally include first name, last name, company, website, and phone. The helper detects common header variations.

Do not include test addresses or contacts without permission. The helper will show the detected mapping before importing and will not silently replace an existing campaign.
